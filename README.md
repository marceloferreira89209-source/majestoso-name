# 🍫 Majestoso Doce - Palhas Italianas Artesanais

Projeto web desenvolvido para a confeitaria artesanal **Majestoso Doce**, especializada em palhas italianas gourmet. A aplicação apresenta o catálogo de produtos com a identidade visual da marca e oferece consulta em tempo real de locais de entrega via API.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização personalizada, layout responsivo e paleta de cores oficial.
- **JavaScript (ES6+)**: Consumo assíncrono de API e manipulação do DOM.
- **API ViaCEP**: Integração para verificação de CEP e suporte à entrega.

## 🛠️ Funcionalidades
- Exibição do cardápio de palhas italianas com preços e descrições.
- Layout responsivo adaptado para dispositivos móveis e desktop.
- Formulário interativo com validação e busca automática de endereços por CEP.
